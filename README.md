# CodeAlpha Internship Tasks

This repository contains my web development projects completed during the CodeAlpha Internship.

## Task 1: Language Translation Tool

### Description
A web-based application that allows users to translate text from one language to another using a translation API.

### Technologies Used
- HTML
- CSS
- JavaScript
- MyMemory Translation API

### Features
- Translate text into different languages.
- English to Urdu translation.
- Urdu to English translation.
- Swap languages.
- Copy translated text.
- Clear text.

### Project Folder
`Language_Translation_Tool`
